# PETG PRO fast, 0.4 mm nozzle

`pla-fast-0.4` machine and process (stock Neptune speeds, 0.2 mm layers, 4 walls, 20% gyroid,
textured PEI) with Orca's **Elegoo PETG PRO @EN3 Series** filament preset, flattened from
`fdm_filament_common → fdm_filament_pet → Elegoo PETG @base → Elegoo PETG PRO @EN3 Series`
(Orca 2.4.2): 230 °C nozzle, 70 °C bed, 8 mm³/s volumetric limit, fan 50–100 %, fan off for the
first 3 layers. First used 2026-11-16 for the Dyson/Bose adapter test parts (sliced, not yet
printed); update this note with the outcome.
